# G ACOUSTICS ENTERTAINMENT — VS Code

Standalone React + Vite + Express version of the website.

## Run

1. Install Node.js 18+ (20+ recommended).
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Open http://localhost:5173

The frontend uses React/Vite. The booking API runs on port 4000 and saves submissions to `server/data/bookings.json`.
